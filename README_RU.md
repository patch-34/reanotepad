# ReaNotepad

[English](README.md) · **Русский**

**Версия 0.5.4** · [Скачать](https://github.com/patch-34/reanotepad/releases) · [Журнал изменений](CHANGELOG.md)

ReaNotepad — редактор структурированных заметок для проектов, дорожек и айтемов REAPER. Документ содержит вкладки, колонки изменяемой ширины, текстовые блоки, заметки с чекбоксами и выпадающие списки. Заметки хранятся в проекте REAPER.

![ReaNotepad в REAPER](assets/screenshot.png)

## Требования

| Компонент | Версия |
| --- | --- |
| REAPER | 7 или новее |
| ReaImGui | 0.10 или новее |

ReaImGui устанавливается через [ReaPack](https://reapack.com/).

## Установка

1. Установите ReaImGui через ReaPack.
2. Скачайте архив релиза и распакуйте `ReaNotepad_v0.5.4.lua` в папку `Scripts` каталога ресурсов REAPER. Каталог открывается командой **Options → Show REAPER resource path in explorer/finder**.
3. Откройте **Actions → Show action list** и выберите раздел **Main**.
4. Выберите **New action → Load ReaScript** и укажите файл `ReaNotepad_v0.5.4.lua`.
5. Выберите добавленное действие и нажмите **Run**.

## Документы и хранение

Переключатель в верхней панели определяет владельца заметок.

| Режим | Владелец | Хранение |
| --- | --- | --- |
| Проект | Текущий проект | Стандартные заметки проекта |
| Дорожка | Одна выбранная дорожка, включая мастер-дорожку | Дополнительные данные дорожки в файле `.rpp` |
| Айтем | Один выбранный айтем | Стандартные заметки айтема |

В режимах Дорожка и Айтем документ следует за выделением в REAPER. У каждого владельца отдельный документ и отдельная история отмены и повтора.

Изменения записываются в открытый проект. Для сохранения на диск необходимо сохранить проект REAPER.

Существующие текстовые заметки отображаются как текстовый блок. Открытие заметок не изменяет их содержимое. При первой правке обычный текст преобразуется в структурированный формат.

## Вкладки, колонки и блоки

Документ состоит из вкладок. На каждой вкладке поддерживается до восьми колонок.

| Операция | Элемент управления |
| --- | --- |
| Создание, переименование, перемещение и удаление вкладок | Меню **Вкладка** |
| Переименование вкладки на месте | Двойной щелчок по вкладке |
| Удаление определённой вкладки | Правый щелчок по вкладке → **Удалить вкладку…** |
| Добавление колонки | **Добавить → Колонка** |
| Изменение ширины колонок | Перетаскивание границы между колонками |
| Переименование колонки | Двойной щелчок по названию или **… → Переименовать колонку…** |
| Перемещение и удаление колонки | Меню **…** колонки |

При переименовании вкладки Enter или щелчок вне поля применяет название; Esc отменяет изменение. Последняя вкладка не удаляется. Пропорции ширины колонок сохраняются в пределах текущего сеанса.

Значки в заголовке колонки добавляют блоки или открывают импорт для этой колонки. При наведении отображается название действия.

| Действие | Результат |
| --- | --- |
| Текст | Многострочный текстовый блок |
| Заметка с чекбоксом | Многострочная заметка с отметкой выполнения |
| Выпадающий список | Именованное поле с редактируемыми вариантами |
| Импорт текста | Диалог импорта |

Те же типы блоков доступны в верхнем меню **Добавить**. Меню **…** блока содержит команды перемещения, назначения цвета и удаления.

### Редактирование

Переключатель **Редактировать** включает изменение текста и отображает управление колонками. При выключенном редактировании текст отображается с переносом строк. Чекбоксы выполнения и выбор значений списка доступны в обоих режимах. Поля редактирования текста используют горизонтальную прокрутку.

Для настройки выпадающего списка выберите **Изменить…** рядом с названием поля или **… → Изменить поле…**. В диалоге доступны изменение названия, редактирование и перестановка вариантов, выбор текущего значения.

Кнопка **Применить** сохраняет изменения диалога. Esc или щелчок вне окна отменяет их. Смена владельца заметок отменяет неприменённые диалоги и переименование вкладки.

## Выделение нескольких блоков

1. Включите **Редактировать**.
2. В меню **…** колонки выберите **Выделить элементы…**.
3. Щелчком выделите необходимые блоки. Повторный щелчок снимает выделение. Выбранные блоки обозначаются рамкой и галочкой в углу.
4. Выполните действие на панели выделения.

| Элемент | Функция |
| --- | --- |
| Все / Снять | Выделение всех видимых блоков колонки или снятие выделения |
| Цвет… | Назначение или удаление цветовой метки |
| Удалить… | Удаление выбранных блоков после подтверждения |
| Готово | Выход из режима выделения |

Во время выделения содержимое блоков доступно только для чтения. Массовое удаление и назначение цвета образуют по одной операции отмены и повтора. В узких колонках кнопки переносятся или заменяются значками с подсказками.

Включение **Скрыть выполненные** снимает выделение со скрытых блоков. Выделение сбрасывается при смене владельца или вкладки, загрузке внешних изменений, отмене или повторе, выходе из редактирования. Esc завершает выделение; при открытом подтверждении удаления сначала отменяется диалог.

## Цветовые метки

Для одного блока используется **… → Цветовая метка**. Для нескольких блоков — **Цвет…** на панели выделения.

Доступны красная, оранжевая, жёлтая, зелёная, синяя и фиолетовая метки. Команда **Без метки** удаляет метку. Фиксированные значения приоритета за цветами не закреплены.

Метка отображается узкой полоской у левого края блока. Текст и фон сохраняют стандартные цвета. Метки сохраняются вместе с документом; их изменение поддерживает отмену и повтор.

## Импорт текста

Импорт открывается командой **Правка → Импорт текста…** или значком импорта в заголовке колонки.

1. Выберите колонку назначения.
2. Вставьте исходный текст в левое поле.
3. Установите **Удалять нумерацию** и проверьте результат в правой области.
4. Нажмите **Импорт**.

Записи добавляются в конец колонки как неотмеченные заметки с чекбоксами. Весь импорт составляет одну операцию отмены и повтора.

Правила разбора:

- Пустые строки разделяют абзацы. Пункты нумерованного списка могут содержать строки продолжения.
- При отсутствии пустых строк и распознанной нумерации каждая непустая строка становится отдельной заметкой.
- Поддерживаются маркеры `1.`, `2)`, `(3)`, `[4]`, `5:`, `6 —` и составные номера вида `1.2.`.
- Номера без знака препинания распознаются по последовательности. Одиночные числа, годы, даты и десятичные дроби сохраняются, если не распознаны как нумерация списка.
- **Удалять нумерацию** включено по умолчанию.

## Вид и язык

| Настройка | Функция |
| --- | --- |
| Скрыть выполненные | Скрытие выполненных заметок с чекбоксами без удаления |
| Шрифт | Размер текста заметок от 12 до 32 px |
| Вид → тема | Выбор Pages, REAPER Grey, Google Docs White или Dark |
| Вид → Язык | Переключение русского и английского интерфейса |
| Контекстное меню верхней панели → Закрепить в докере | Закрепление и открепление окна |

Размер шрифта интерфейса не зависит от размера текста заметок. Смена языка затрагивает элементы интерфейса; текст документа и пользовательские названия сохраняются.

## Отмена и повтор

Меню **Правка** отображает следующие действия отмены и повтора.

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Отмена | Ctrl+Z | Cmd+Z |
| Повтор | Ctrl+Shift+Z или Ctrl+Y | Cmd+Shift+Z или Cmd+Y |

История включает правки текста, изменение структуры, отметки выполнения, выбор значений списка, импорт, цветовые метки и восстановление. Последовательный ввод или удаление в одном поле объединяется с порогом паузы около 0,8 секунды. Перемещение курсора, изменение выделения текста, вставка, вырезание, замена и перевод строки разделяют операции редактирования.

История ведётся отдельно для каждого владельца в пределах сеанса скрипта. Каждый стек содержит до 100 записей с ограничением около 16 МиБ. Перезапуск скрипта или загрузка внешних изменений сбрасывает соответствующую историю. Настройки оформления в историю документа не входят.

## Восстановление

Повреждённые документы и неподдерживаемые форматы открываются только для чтения. Внешние изменения загружаются при отсутствии ожидающих локальных правок. Конфликт изменений приостанавливает запись и сопровождается диагностическим сообщением.

Каталог аварийных копий:

```text
<каталог ресурсов REAPER>/Data/Patch34_Project_Notes_Recovery/
```

В состав копии могут входить исходные заметки, локальный черновик, текст неприменённого диалога и диагностический отчёт.

Для восстановления выберите **Правка → Открыть аварийную копию…**, откройте файл `.notes`, проверьте предпросмотр и нажмите **Восстановить**. Копия заменяет документ текущего владельца. Восстановление поддерживает отмену и повтор.

## Совместимость формата

- Формат хранения — v2. Документы v1 преобразуются при редактировании.
- Цветовые метки используют необязательные директивы `@color`. Версии до 0.5.3 включительно открывают документы с этими директивами только для чтения. Для редактирования в более ранней версии необходимо предварительно удалить все метки в 0.5.4.
- Простые чекбоксы из прежних версий поддерживаются.
- Внутренние ключи хранения Patch34 сохранены для совместимости существующих заметок и настроек.
