# ReaNotepad

[English](README.md) · **Русский**

ReaNotepad — Lua-редактор структурированных заметок для проектов, дорожек и айтемов REAPER. Списки правок, задачи, заметки к монтажу и статусы объединяются в горизонтальные вкладки и сворачиваемые группы. Данные хранятся непосредственно в проекте REAPER, без отдельных рабочих файлов.

## Требования и установка

- **REAPER 7+**, **ReaImGui 0.10+** (устанавливается через [ReaPack](https://reapack.com/)). SWS не требуется.
- Сохрани `ReaNotepad.lua` в папку `Scripts` каталога ресурсов REAPER. Путь можно открыть через **Options → Show REAPER resource path**.
- Открой **Actions → Show action list → Main → New action → Load ReaScript** и выбери `ReaNotepad.lua`.
- Для обновления **замени прежний файл, не меняя его имя**: тогда сохранятся привязки действия, горячие клавиши и кнопки панелей REAPER.

[Индекс Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) обновляется отдельно; версия в нём может временно отличаться от GitHub.

### Докер и изменение размеров (v0.7.1)

Версия 0.7.1 исправляет сбой ReaImGui при перемещении окна ReaNotepad между областями Docker или откреплении окна. Также добавлена защита вычисления ширины заметок при очень узкой панели. Для обновления замени существующий `ReaNotepad.lua` по тому же пути.

## Документы и хранение

| Режим | Владелец | Где хранятся заметки |
| --- | --- | --- |
| Проект | Текущий проект REAPER | Стандартные Project Notes (`GetSetProjectNotes`) |
| Дорожка | Ровно одна выделенная дорожка, включая мастер | `P_EXT:PATCH34_PROJECT_NOTES` внутри `.rpp` |
| Айтем | Ровно один выделенный айтем | Стандартные `P_NOTES` |

Выбор владельца расположен в верхней панели. У каждого владельца собственный документ и отдельная история Undo/Redo в пределах работы скрипта. Для записи изменений на диск **сохраняй проект REAPER**. Простое открытие прежних текстовых заметок их не переписывает.

В документе может быть до восьми горизонтальных вкладок. Внутри — сворачиваемые **группы** с текстовыми заметками, задачами с чекбоксом и именованными выпадающими списками. Вкладки и заметки можно упорядочивать перетаскиванием; заметки — переносить между группами.

## Создание и редактирование

- В верхней панели и меню **Добавить** находятся текстовые заметки, чекбоксы, выпадающие списки и импорт. Можно нажать значок и выбрать группу или перетащить значок на группу.
- Светлая иконка **плюс в кружке** внизу развёрнутой группы сразу создаёт в ней заметку с пустым чекбоксом.
- У заметки есть меню **«…»** без рамки, в стиле заголовка группы. В нём находятся действия с заметкой, выбор цвета, добавление или удаление чекбокса (для текстовых заметок), перемещение и удаление.
- Нажатие на текст переводит заметку в режим правки: **Enter** — сохранение; **Shift+Enter** — перевод строки; **Esc** — подтверждение отмены изменённого текста. Щелчок вне поля применяет изменения.
- Нажатие на чекбокс меняет статус выполнения. Выпадающий список позволяет выбирать значение; его настройки доступны из меню **«…»**.
- Ручка из шести точек слева предназначена для перемещения заметок. При перетаскивании в верхней панели появляется корзина.
- Через **«…»** заголовка группы можно изменить её название и цвет, переместить выше или ниже, создать группу ниже, включить выделение и удалить группу. Последняя группа вкладки не удаляется.

## Выделение и оформление

Команда **«… → Выделить элементы…»** в меню группы включает множественное выделение видимых заметок. Панель выделения позволяет отметить все, снять выделение, изменить цвет и удалить выбранные записи.

В меню **Вид** есть настройки «Скрыть выполненные», «Выполненные в конце», оформление цветной полоской или заливкой, **интервал между заметками** (0–24 px, по умолчанию 5 px), темы Pages, REAPER Grey, Google Docs White и Dark, переключение языка. Размер шрифта заметок — **12–32 px**. Ползунки шрифта и интервала используют штатный ReaImGui `SliderInt`, единицы в обоих языках — `px`. Настройки оформления не добавляют шагов Undo документа.

## Импорт текста и таймкоды

Выбери **Правка → Импорт текста…**, вставь материал, укажи группу и проверь предпросмотр. Доступны **Удалять нумерацию** и **Разделять по таймкодам**. Весь импорт выполняется одним действием Undo. Распознаются разные типы нумерации: `1.`, `2)`, `(3)`, `[4]`, `5:`, `6 —` и составные номера.

Таймкоды в начале заметки распознаются независимо от настройки разделения:

| Пример | Значение |
| --- | --- |
| `01:45` | ММ:СС |
| `00:00:12` | ЧЧ:ММ:СС |
| `00:01:35:04` | ЧЧ:ММ:СС:КК, с учётом FPS проекта |
| `00:01:35.250` | Время с миллисекундами |

**Одинарный щелчок по таймкоду** переводит edit cursor в соответствующую позицию и передаёт фокус arrange view REAPER, чтобы можно было сразу запустить воспроизведение пробелом. Учитывается стартовое смещение проекта. Четырёхпольные таймкоды учитывают FPS и drop-frame. Исходный текст не изменяется.

## Undo/Redo, восстановление и совместимость

Undo/Redo охватывает редактирование текста, чекбоксы, выпадающие списки, импорт, цветовые метки, изменения групп/вкладок, перетаскивание и восстановление аварийных копий. Для каждого владельца действует отдельная история — до 100 шагов или около 16 МиБ на стек. Близкие по времени текстовые изменения объединяются. После перезапуска скрипта история не сохраняется.

При внешнем изменении нативных заметок запись приостанавливается, чтобы не затереть чужие правки. Повреждённые или неизвестные структурированные форматы открываются только для чтения. Аварийные копии находятся в `Data/Patch34_Project_Notes_Recovery/`. Восстановление — через **Правка → Открыть аварийную копию…**, с обязательной проверкой файла.

**Версия 0.7.1 сохраняет формат документа v3** (`# Patch34 Project Notes v3`). Старые v1/v2 и обычные текстовые заметки по-прежнему читаются. Внутренние ключи хранения, настройки, идентификаторы окон и пути аварийных копий **не переименованы**, чтобы сохранить совместимость. Более старые версии скрипта могут не поддерживать редактирование документов v3.
