The original SVG paths are preserved in this folder. The embedded PNG masks use white strokes, a stroke width of 1.5 on the original 24-unit grid, and a 96 × 96 raster. ReaImGui displays them at up to 16 logical pixels and tints them with the theme text color. The SVG files are not runtime dependencies; the Lua file contains the icons required by the interface.
