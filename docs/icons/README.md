# Quick-action icons

Source: https://github.com/lucide-icons/lucide/tree/main/icons
Retrieved: 2026-10-29.

| Action | Lucide icon |
| --- | --- |
| Text | type |
| Checkbox note | square-check |
| Dropdown | list-chevrons-down-up |
| Import | file-input |

The original SVG paths are preserved in this folder. The embedded PNG masks use white strokes, a stroke width of 1.5 on the original 24-unit grid, and a 96 × 96 raster. ReaImGui displays them at up to 16 logical pixels and tints them with the theme text color.

The Lucide ISC license and the Feather MIT license for type are included in ../licenses/LUCIDE_LICENSE.txt and the standalone Lua. These licenses apply to the icons, not to the script as a whole.
