# ReaNotepad v0.7.1

This maintenance release fixes an intermittent crash when moving or resizing the ReaNotepad Docker in REAPER.

### Fixes

- Fixed `ImGui_End: Calling End() too many times!` when moving ReaNotepad between docking positions or undocking the window.
- Corrected ReaImGui window/child scope handling throughout the script: `End()` and `EndChild()` are only called for successful `Begin()` and `BeginChild()` calls.
- Added a minimum-width guard for note layout when the Docker becomes narrower than its content.

### Compatibility

- Requires **REAPER 7+** and **ReaImGui 0.10+**. SWS is not required.
- No changes to document format **v3**, project/track/item notes, saved preferences, or Undo/Redo.
- Upgrading from v0.7.0: replace your existing `ReaNotepad.lua` file without renaming it. This preserves REAPER actions and shortcuts.

### Validation

The user confirmed that the corrected development build works in REAPER, including moving the Docker. The released Lua differs from that tested build only in the version strings.
